# Provenance

Namebench retains the history of the original name generator, starting at commit `d90bd7a` on March 4, 2026. No replacement repository was initialized locally.

The standalone version adds packaging, pinned runtime dependencies, a bundled hand-authored demo, browser checks and documentation. The world database and raw sources remain local ignored files. No map engine, genealogy engine, credentials or virtual environment is distributed.

The GitHub repository was renamed in place. Its existing commits are preserved.
